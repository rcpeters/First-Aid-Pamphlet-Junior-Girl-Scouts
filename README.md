# Girl Scout Junior First Aid Handbook

A 16-page, half-letter (`5.5" × 8.5"`) printable first aid pamphlet written for Girl Scout Juniors (around 10 years old). **Please note this was AI generated by an amateur for a single meeting and is not intended to be a comprehensive guide.**

## Files

- `Junior-First-Aid-Handbook.pdf` — Ready-to-print 16-page booklet (sequential pages; print using **Booklet** mode on standard `8.5" × 11"` paper, double-sided, then fold and staple).
- `build-handbook.js` — Single Node.js generator script that builds the PDF from scratch with no external dependencies, checks for vertical overflow, and prints `No layout warnings.` when clean.

## Rebuilding the PDF

1. Close `Junior-First-Aid-Handbook.pdf` if it is open in a PDF viewer (otherwise Windows will lock the file with `EBUSY`).
2. Run:

```powershell
node build-handbook.js
```

## Updating with an LLM in the Future

When asking an AI assistant to update this pamphlet:

1. **Direct it to `build-handbook.js`:** Tell it `build-handbook.js` is the single source of truth and to rebuild `Junior-First-Aid-Handbook.pdf` afterward.
2. **State the target audience & format:** Keep language simple for ~10-year-olds, preserve color + black-and-white readability, keep per-topic headers, and keep the total page count a multiple of 4 (currently 16 pages) for booklet printing.
3. **Ask it to verify the build:** Have it confirm `node build-handbook.js` outputs `No layout warnings.` and visually inspect any modified pages in the generated PDF.
4. **Provide authoritative links for medical changes:** First aid protocols evolve (for example, the 2025 choking update). Include a current Mayo Clinic, Red Cross, or AHA link when requesting medical updates.

### Example Prompts

- *"In `build-handbook.js`, update the [topic] section to match [link/guideline]. Keep it simple for 10-year-olds, rebuild `Junior-First-Aid-Handbook.pdf`, and verify there are no layout warnings."*
